# Simplified Financial Reporting System

This repository defines a clean, practical reporting workflow built around **Google Sheets as the only data input**. The system avoids unnecessary infrastructure while still supporting automated dashboards, premium PDF reports, multilingual reporting, and searchable report archives.

## Core Principle

Use the Google Workspace stack as the operating system for reporting:

```text
Manual financial entry
        ↓
Google Sheets source workbook
        ↓
Spreadsheet KPI calculations
        ↓
Looker Studio dashboard + Google Apps Script report automation
        ↓
PDF reports archived in Google Drive
```

No custom databases, data warehouses, backend services, queues, or enterprise orchestration are required for the standard workflow.

## System Components

| Component | Purpose |
| --- | --- |
| Google Sheets | Only data input, manual financial entry, KPI calculations, reporting control panel |
| Looker Studio | Live dashboard connected directly to Google Sheets |
| Google Slides | Premium report templates for English, Turkish, and Arabic |
| Google Apps Script | Automation for report generation, PDF export, scheduling, and archiving |
| Google Drive | Permanent report archive with searchable folder and file naming structure |

## Workflow

### 1. Manual Financial Input

The finance team enters values only in protected input tabs inside Google Sheets. Recommended tabs:

- `Input_Daily`
- `Input_Weekly`
- `Input_Monthly`
- `Input_Yearly`
- `Chart_Data`
- `KPI_Output`
- `Report_Control`
- `Archive_Index`

Input tabs should contain only clean financial values, dates, entities, currencies, and notes. Formula tabs should be protected to prevent accidental edits.

### 2. KPI Auto-Calculation

Google Sheets calculates all report-ready KPIs using formulas, named ranges, and structured tabs. KPI examples:

- Revenue
- Gross profit
- Gross margin
- Operating expenses
- EBITDA
- EBITDA margin
- Net profit
- Cash balance
- Budget variance
- Month-over-month change
- Year-over-year change

`KPI_Output` should expose final values in a stable structure consumed by dashboards and report automation.

### 3. Live Dashboard Updates

Looker Studio connects directly to the Google Sheets workbook. When spreadsheet data changes, dashboard visuals refresh from the same source of truth.

Recommended dashboard pages:

- Executive Summary
- Revenue Performance
- Profitability
- Cost Analysis
- Cash Position
- Budget vs Actual
- Historical Trends

### 4. Automated PDF Generation

Google Apps Script reads `Report_Control` and `KPI_Output`, selects the correct Google Slides template, replaces placeholders, refreshes charts/tables, exports the result as PDF, and stores it in Google Drive.

Supported report frequencies:

- Daily
- Weekly
- Monthly
- Yearly

Supported languages:

- English (`en`)
- Turkish (`tr`)
- Arabic (`ar`)

Use one premium Google Slides template per language and report frequency when layout differences are required:

```text
Templates/
  EN/
    Daily_Report_Template
    Weekly_Report_Template
    Monthly_Report_Template
    Yearly_Report_Template
  TR/
    Daily_Report_Template
    Weekly_Report_Template
    Monthly_Report_Template
    Yearly_Report_Template
  AR/
    Daily_Report_Template
    Weekly_Report_Template
    Monthly_Report_Template
    Yearly_Report_Template
```

Arabic templates should use right-to-left layouts, Arabic fonts, and mirrored chart/table alignment where appropriate.

### 5. Automatic Archive System

Every generated PDF is saved permanently to Google Drive with a predictable folder hierarchy:

```text
Financial Reports Archive/
  2026/
    Daily/
      EN/
      TR/
      AR/
    Weekly/
      EN/
      TR/
      AR/
    Monthly/
      EN/
      TR/
      AR/
    Yearly/
      EN/
      TR/
      AR/
```

Recommended file naming convention:

```text
YYYY-MM-DD_Company_ReportFrequency_Language_Version.pdf
```

Examples:

```text
2026-05-09_Acme_Daily_EN_v001.pdf
2026-05-09_Acme_Daily_TR_v001.pdf
2026-05-09_Acme_Daily_AR_v001.pdf
2026-05_Acme_Monthly_EN_v001.pdf
```

Each generated report should also be logged in `Archive_Index` with:

- Generated timestamp
- Reporting period
- Frequency
- Language
- File name
- Google Drive file URL
- Template version
- Generated by
- Status

This keeps historical reports searchable from both Google Drive and the spreadsheet index.

## Automation Model

Use Google Apps Script time-based triggers and manual control buttons.

| Automation | Trigger |
| --- | --- |
| Daily report | Every business day after financial entry cutoff |
| Weekly report | Weekly, after week close |
| Monthly report | Monthly, after month close |
| Yearly report | Yearly, after annual close |
| Manual regeneration | Button or custom menu in Google Sheets |

Recommended `Report_Control` fields:

- Company/entity
- Report frequency
- Reporting period start
- Reporting period end
- Language
- Template ID
- Archive folder ID
- Generate now flag
- Report status
- Last generated file URL

## Professional Design Standards

Reports should look premium and board-ready:

- Clean executive cover page
- Consistent typography and spacing
- Strong financial summary section
- KPI cards with clear variance indicators
- Minimal color palette using brand colors
- Charts optimized for financial interpretation
- Notes and assumptions page
- Footer with period, language, version, and confidentiality label

## Scalability Without Overengineering

This setup scales by adding structured sheets, templates, and archive folders rather than new infrastructure.

Recommended boundaries:

- Keep Google Sheets as the only manual input source.
- Keep formulas centralized in protected calculation tabs.
- Keep report generation in Google Apps Script.
- Keep dashboards in Looker Studio.
- Keep all generated files in Google Drive.
- Add external infrastructure only if Google Workspace limits are clearly exceeded.

## Maintenance Rules

- One workbook is the source of truth.
- Input tabs are editable only by finance contributors.
- Formula and output tabs are protected.
- Templates are versioned and duplicated before major design changes.
- Apps Script writes every generated PDF to `Archive_Index`.
- Naming conventions are never changed retroactively.
- Historical PDFs are never overwritten; regenerations create a new version.

## Implementation Checklist

1. Create the Google Sheets source workbook.
2. Add protected input, calculation, output, control, and archive index tabs.
3. Build KPI formulas in `KPI_Output`.
4. Connect Looker Studio directly to the workbook.
5. Design premium Google Slides templates for English, Turkish, and Arabic.
6. Add Google Apps Script automation for template population, PDF export, and Drive archiving.
7. Add scheduled triggers for daily, weekly, monthly, and yearly reports.
8. Test each language and frequency combination.
9. Confirm every generated PDF appears in Drive and `Archive_Index`.
10. Train the finance team to use only the input tabs and report control menu.
